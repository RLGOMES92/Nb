# NB Diogo — Gestão e Orçamentos

Aplicação web para centralizar o cadastro de clientes e a elaboração de propostas e orçamentos.

## Funcionalidades
- Cadastro e organização de clientes
- Fluxo de elaboração de propostas e orçamentos
- Geração de documentos em PDF
- Exportação de dados para XLSX
- Interface responsiva

## Tecnologias
- React
- Firebase
- jsPDF
- XLSX
- HTML, CSS e JavaScript

## Objetivo
Centralizar o processo de atendimento e elaboração de propostas em uma aplicação web responsiva.

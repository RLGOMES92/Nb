# 📊 NB Diogo — Gestão e Orçamentos

Aplicação web para **centralizar clientes, propostas e orçamentos**, reduzindo tarefas manuais e organizando o atendimento comercial em um único fluxo.

## Problema de negócio

Pequenos negócios que elaboram propostas e orçamentos podem perder tempo alternando entre planilhas, documentos e diferentes ferramentas.

## Solução desenvolvida

Uma aplicação responsiva que reúne cadastro de clientes, criação de propostas, geração de documentos e exportação de dados, formando uma base para um processo comercial mais organizado.

## Funcionalidades

- Cadastro e organização de clientes
- Criação e gerenciamento de propostas e orçamentos
- Geração de documentos em PDF
- Exportação de dados para XLSX
- Interface responsiva
- Persistência de dados com Firebase

## Tecnologias

- React
- Firebase
- jsPDF
- XLSX
- JavaScript
- HTML/CSS

## Aplicação comercial

A solução pode ser adaptada para **prestadores de serviços, escritórios, empresas de manutenção, construção, vendas e negócios que trabalham com orçamento personalizado**.

## Objetivo do projeto

Demonstrar como desenvolvimento web pode transformar processos operacionais em ferramentas digitais mais organizadas e escaláveis.
